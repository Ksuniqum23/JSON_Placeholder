# TypeORM + PostgreSQL: работа с сущностями

## DataSource
- Мост между бэкендом и PostgreSQL
- Хранит настройки подключения (хост, порт, логин, пароль, БД)
- Регистрирует все сущности

## Репозиторий
- Инструмент для работы с конкретной таблицей
- Получается через `AppDataSource.getRepository(Entity)`
- Содержит методы: `find`, `save`, `delete`, `update`

## Цепочка запроса
Запрос от фронта → Контроллер → Репозиторий → База данных → Ответ фронту

## Методы репозитория
- `find()` — получить все записи
- `findOne({ where: { id } })` — получить одну запись
- `save(entity)` — создать или обновить
- `delete(id)` — удалить
- `update(id, data)` — обновить

## Сущности с вложенными объектами
- `@Entity()` — класс, который становится таблицей
- `@Embeddable()` (не нужен в TypeORM 0.3+) — вложенный класс без декоратора
- `@Column(() => EmbedClass)` — встраивание вложенного объекта
